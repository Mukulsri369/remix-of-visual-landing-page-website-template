- **Key Value**:Communicates Monolith Storefront's core value propositions (One-Time Ownership, Zero Merchant Liability, Automated Link Ingestion, Cross-Border Geo-Routing, and Bespoke Themes) inside the high-impact visual storytelling layout.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: Strict Visual Preservation**
  - *Chosen Approach*: Keep all CSS classes, animations, video embeds, darkroom clotheslines, film strips, and wanted poster layouts completely intact while replacing text strings and form fields.
  - *Why*: Directly fulfills your instruction ("dont change the visuals, just change the text and brand name other details which need to change").
- **Decision 2: Runtime Port & Build Alignment**
  - *Chosen Approach*: Configure the Vite dev server to run on port `3000` (`0.0.0.0`) so the preview loads seamlessly in AI Studio.
  - *Why*: Required by the AI Studio runtime environment.
